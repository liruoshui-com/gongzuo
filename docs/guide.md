# 使用说明

## 运行与模型设置

安装 Node.js 22 或更新版本，进入项目目录运行 `npm start`，在浏览器打开 http://127.0.0.1:4318。关闭服务后，已保存的任务仍在项目目录；再次启动即可读取。

若 Windows 保留了默认端口，应用会尝试切换到 14318；请以启动窗口打印的地址为准。也可通过 `PORT` 环境变量指定端口，显式指定时不会自动改用其他端口。

模型设置支持 DeepSeek、OpenAI、智谱 GLM（国内）和 Claude。选择服务、输入 API 密钥并保存即可使用预设。密钥分别保存；留空保留已有密钥，勾选删除则清除。更改接口地址或协议后，旧密钥会清除，需要重新输入。

高级设置可以修改模型名、基础地址、协议及调用边界，也可以接入兼容本机服务。原生接口分别为 OpenAI Responses、兼容 Chat Completions 和 Claude Messages。不同账号的模型权限与额度可能不同；「已配置」仅表示必要字段齐全，不代表已经成功连接。

预设核对日期：2026-09-11；模型名称可能需要根据服务商变更调整。

| 服务 | 默认模型 | 官方接口说明 |
| --- | --- | --- |
| OpenAI | gpt-5.4-mini | [Responses / Function calling](https://developers.openai.com/api/docs/guides/function-calling) |
| DeepSeek | deepseek-v4-flash | [首次调用](https://api-docs.deepseek.com/) |
| 智谱 GLM | glm-4.7-flash | [GLM Flash 文档](https://docs.bigmodel.cn/cn/guide/models/free/glm-4.7-flash) |
| Claude | claude-sonnet-5 | [Messages API](https://platform.claude.com/docs/en/api/messages/create) |

「测试已保存连接」使用一条工具调用请求，产生少量实际用量。接口响应与工具响应分别检查；最近 100 次测试记录可在设置中查看。没有配置价格，应用不显示估算金额。

## 做一个任务

1. 写下目标，补充个人要求和验收条件。
2. 导入手头材料，或在补充说明中提供上下文。
3. 运行本地 CSV 工具，或选择模型后开始 AI 执行。
4. 查看执行过程；缺少关键判断时补充信息后继续。
5. 打开成果检查，下载文件。修改意见保存后可以再次执行。
6. 确认某个成果版本确实可用后，勾选人工验收。

停止执行会取消后续调用，保留此前成功保存的材料与成果。被中断的模型请求可能已经计费却未返回用量，此时显示未知。

模型建议、文件结构检查和人工验收是不同的记录。执行失败、调用上限或保存失败会显示具体缺口，不会自动视为成果合格。

## 材料和成果

- 输入：UTF-8 TXT、Markdown、CSV、JSON。每份最多 200,000 字符；每任务最多 20 份、合计 600,000 字符。
- 输出：文本、Markdown、CSV、JSON、SVG、自包含 HTML。每份最多 300,000 字符，同名同类型保留版本。
- 本版最多保存 50 个任务、每任务 100 个成果版本，任务存储总量上限 50 MB。
- 任务可以导出 JSON；应用内导入与归档尚未实现。大批量使用前请考虑当前限制。

原始材料不会被清洗结果覆盖。CSV 可以修剪首尾空白、移除空行、可选去重，以及按列计数或汇总。非空数据整列都满足普通数字格式时才计算；使用 JavaScript 浮点数，不替代高精度财务核算。超安全整数范围的值不参与数值汇总。

CSV 导出对以公式字符开头的单元格加单引号，避免电子表格自动执行；负数也会被导出为文本。保留原始值供核对，导出的数字类型需要根据实际用途检查。

## HTML 产品试用与下载

生成的 HTML 在隔离 iframe 中运行；远程脚本、联网请求、表单提交和父页面访问受到限制。产品需要自包含，使用 `localStorage.getItem/setItem/removeItem/clear`，不支持 IndexedDB、service worker 或属性式 `localStorage.foo`。

预览数据按成果版本保存在本机。新版本不会自动迁移旧版本的数据；切回旧版可以继续查看。下载的 HTML 包含该版当前预览数据，并在浏览器允许本地文件存储时保存后续操作。存储不可用时会显示提示。

加载成功只能证明页面加载，不能证明功能符合需求。请实际检查添加、编辑、删除、刷新和导出等关键操作。

## Token 与效率

应用先提供材料目录，再由工具按需读取；同一轮执行仍会累积上下文。调用和工具轮数有边界，但这本身不能证明较普通聊天更省。

每个请求保留服务商实际返回的输入、输出、缓存与推理明细。缓存和推理不重复叠加；Claude 输入由适配层归一化。用量缺失时显示未知。

token 软上限按每轮执行计算，到达后停止后续请求；最后一次仍可能超出，继续执行会开始新一轮上限。联网搜索还可能有独立工具费用。连接测试用量单独列出。

## 上下文体检

任务中的「上下文体检」用本机程序检查下一次执行准备带入的信息，并记录后续模型请求的元数据。打开体检、固定要求、人工标记和导出报告都不会请求模型；无密钥时也能预检。

**先检查下次执行。**目标、个人要求、验收条件、固定要求、最近 12 条补充、当前计划、材料目录和最近 20 个成果目录进入起始任务信息。较早的补充与成果目录会标明遗漏。空白的可选要求显示未填写，不算遗忘。

**固定重要要求。**最多 12 项，每项最多 800 字符。它们会出现在下一轮执行的每次模型请求中，可以撤销固定。固定不会自动执行任务；修改后请重新检查已有成果。固定内容本身会增加输入长度，应保留重要且简短的约束。超过 800 字符的旧补充需要你提炼后再固定。

**按请求回看。**每次请求在发送前保存快照，对应同一条用量记录。可以看到当时哪些要求完整带入、哪些较早补充被排除，以及匹配内容在前后请求中的消失。历史页只显示当时的标识、类型与字符数，不会用当前文本冒充历史文本。记录存在表示应用已准备输入；失败或取消不能据此认定服务商收到请求。

**目录和正文分开。**材料目录只含文件信息；只有读取工具成功且结果进入下一次请求，才显示已带入的切片。范围按内容版本区分，重叠字符去重统计。CSV 的完整处理发生在本机，模型只收到分析摘要与成果信息。重复读取可能是合理复核，不等于可节省的 token。每次「继续执行」都会重建上下文，上一轮回复、工具结果和材料片段不会自动续接，需要重新读取。新一轮预检因此从目录状态开始。

**人工核对结果。**对已有有效返回且确实包含的要求，可以标记「结果未遵守」。这只记录你的判断，不是自动质量评估，也不会自动启动修复。要修改成果，可在补充框说明具体问题后继续执行。

报告保存请求和任务标识、哈希、时间、模型名、字符/字节数、读取范围、检查结果和返回用量；不额外保存完整提示词、文件正文、请求头或推理内容。每任务保留最近 120 次请求快照，较早快照数量单独提示。升级前的旧调用没有追踪证据，显示未记录；缺失用量仍为未知。原任务导出仍包含完整任务材料，与体检导出不同。

字符以 JavaScript UTF-16 长度计数，不是 token；请求字节以 UTF-8 计数。只显示服务商实际返回的 token，不猜测上下文窗口占比或服务端截断。体检能查明应用输入的变化，不能证明模型理解、注意到或落实了信息，也尚未证明任务总成本下降。

## 数据、备份和安全

```text
.local-data/config.json        各服务配置与 API 密钥（明文）
.local-data/workspace.json     任务、材料、成果、预览与连接测试
.local-data/workspace.json.bak 最近一次替换前的任务备份
```

`.local-data/` 已忽略 Git，应用不会把密钥放入任务导出或发给模型。任务导出仍包含你自己的材料与成果，分享前需检查。

服务只监听本机并校验 Host / Origin；它不具备公网账号或多人权限。开始 AI 执行时，会将任务要求及按需读取的材料发送给所选服务。

恢复备份时，先停止服务、保留损坏文件，再把 `workspace.json.bak` 复制为 `workspace.json`。浏览器旧示例的数据仍保存在 `co-work-prototype-v1`；新任务保存在本机服务端。

## 尚未支持

原生 PDF / Word / Excel 文件、外部办公软件操作、任意主机代码执行、云同步、跨任务偏好学习、自动模型分工、自动及格评估。联网搜索目前仅支持启用后的 OpenAI 官方 Responses 接口。
